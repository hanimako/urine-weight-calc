# Urine Weight Calculator

使用済みオムツなどの重量から、尿量の目安を計算するアプリです。

使用したオムツやパッドを選択すると、製品自体の重量を差し引いて計算します。

## デモ

https://urine-weight-calc.vercel.app/

## 使用技術

- Next.js
- React
- TypeScript
- Tailwind CSS

## ローカルでの実行

```bash
git clone https://github.com/hanimako/urine-weight-calc.git
cd urine-weight-calc
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。
